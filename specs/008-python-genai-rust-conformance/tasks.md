# Tasks: Python google-genai Conformance (Gemini Developer API)

**Input**: `specs/008-python-genai-rust-conformance/{spec,plan,research,data-model,quickstart}.md`, `contracts/*`
**Repo root** (`$R`): the repository root
**Scratchpad** (`$S`): a scratch directory outside the repository
**Format**: `- [ ] T### [P?] [US?] description with file path`. `[P]` = touches only its own files; safe to run concurrently.

## Common prerequisites (apply to EVERY task)

- **CP-1 Absolute paths**: all repo operations use absolute paths under `$R` (the shell cwd drifts between calls). Start commands with `cd $R`.
- **CP-2 Shell output**: redirect command output to a file under `$S` (`> $S/<name>.log 2>&1`), then read with `grep -n`/`sed -n 'N,Mp'`. Never dump logs into the conversation. Report counts, exit codes, and matching lines only.
- **CP-3 Python tooling**: run codegen with `PY=$R/target/codegen-venv/bin/python` (created by T001). Never use pyenv 3.14 for generation.
- **CP-4 Parallel cargo**: any task run concurrently with another `cargo` task MUST begin with `export CARGO_TARGET_DIR=$R/target-agents/<task-id>`; after the batch finishes the orchestrator runs `rm -rf $R/target-agents`. Sequential tasks use the default `target/`.
- **CP-5 Generated files**: never hand-edit `src/types/generated/`, `src/converters/generated/`, `src/blocking/generated.rs`, `src/gaos/**`, `tests/fixtures/converters/**`, `tests/fixtures/upstream/**`, `tests/fixtures/gaos/**`, `docs/parity*.md`, `tools/codegen/ledger.toml`. Change the generator and re-run `$PY tools/codegen/generate.py`.
- **CP-6 Rust rules** (the Rust best-practice rules (Apollo GraphQL handbook based) + `AGENTS.md`): no `unwrap`/`expect`/`panic!` outside `#[cfg(test)]`; `thiserror` typed errors; borrow over clone; named constants for identifier strings; `///` docs on every public item (`missing_docs = deny`); lint suppression only as `#[expect(lint, reason = "…")]`; no logging of API keys or bodies.
- **CP-7 Gate G** (run at the end of every phase, outputs to `$S/gate.log`): `cargo fmt --all --check` · `cargo clippy --workspace --all-targets --all-features --locked -- -D warnings` · `cargo test --workspace --all-features` · `RUSTDOCFLAGS="-D warnings" cargo doc --no-deps --all-features` · `$PY tools/codegen/generate.py && git diff --exit-code -- . ':!specs'` (from P2 on also `check_ledger.py`; from P3 on also `check_upstream_tests.py`). A phase is done only when Gate G exits 0.
- **CP-8 Git**: do not commit or rewrite history inside tasks; the orchestrator commits at the end (`/github-commit all`). Do not touch `git stash` (it holds the discarded 007 WIP).
- **CP-9 Upstream source**: `UP=$R/target/upstream-src/v2.28.0` (made by T003). Python test sources: `$UP/google/genai/tests`.
