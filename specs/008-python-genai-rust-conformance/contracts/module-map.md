# Contract: upstream module → Rust file

Rule: one Rust file (or the listed dir) per upstream module; leading `_` dropped; Rust names = `snake_case`/`PascalCase` of upstream names; definition order follows upstream. `tools/codegen/module_map.toml` encodes this table; the ledger check reads it.

| Upstream (`google/genai/…`) | Rust | Action in this feature |
|---|---|---|
| `__init__.py` | `src/lib.rs` | keep; add `pub const VERSION` mirror only if absent |
| `version.py` | `src/lib.rs` | `merged` into `lib.rs` (version exposed via `env!("CARGO_PKG_VERSION")`; no separate file) |
| `client.py` | `src/client.rs` | add accessors for new modules |
| `_base_url.py` | `src/base_url.rs` | NEW: move base-URL/env resolution out of `client.rs` (functions `get_base_url`, `set_default_base_urls`… as upstream names them, snake_case) |
| `_api_client.py` | `src/api_client/` | rename dir `src/http/` → `src/api_client/` |
| `_api_module.py` | — | `not_ported`: structural base class; Rust handles hold `Arc<ApiClient>` |
| `_common.py` | `src/common.rs` | NEW: move `getv/setv/…` helpers from `src/converters/mod.rs` |
| `_base_transformers.py` | `src/base_transformers.rs` | NEW: split from `transformers.rs` |
| `_transformers.py` | `src/transformers.rs` | keep; align order with upstream |
| `_extra_utils.py` | `src/extra_utils.rs` | NEW: split from `afc.rs` |
| `_automatic_function_calling_util.py` | `src/automatic_function_calling_util.rs` | NEW: split from `afc.rs`; `src/afc.rs` is deleted |
| `_mcp_utils.py` | `src/mcp_utils.rs` | rename `src/mcp.rs` |
| `_adapters.py` | — | `not_ported` (reason_code `python_only`): MCP session adapter class; Rust exposes MCP tools through `mcp_utils.rs` |
| `_live_converters.py`, `_tokens_converters.py`, `_operations_converters.py` | `src/converters/generated/<same stem minus _>.rs` | regenerate (2.28.0) |
| `models.py batches.py caches.py files.py tunings.py file_search_stores.py documents.py operations.py chats.py` | `src/<same>.rs` | keep; align |
| `pagers.py` | `src/pagers.rs` | rename `pager.rs` |
| `errors.py` | `src/errors.rs` | rename `error.rs` |
| `tokens.py` | `src/tokens.rs` | rename `auth_tokens.rs`; accessor stays `client.auth_tokens()` (upstream property name) |
| `live.py`, `live_music.py` | `src/live.rs`, `src/live_music.rs` | flatten `src/live/mod.rs`, `src/live/music.rs` |
| `types.py` | `src/types/**` | generated + ext/http/conversions (unchanged) |
| `agents.py environments.py triggers.py webhooks.py voices.py credentials.py interactions.py` | `src/<same>.rs` | NEW: re-export generated gaos types by upstream `__all__` names; handle structs live in `src/gaos/resources/` |
| `_gaos/**` | `src/gaos/**` | NEW, generated by `gen_gaos.py` |
| `local_tokenizer.py`, `_local_tokenizer_loader.py` | — | `not_ported`, `python_only`: needs sentencepiece model download; no API request behavior |
| `_replay_api_client.py`, `_test_api_client.py` | — | `not_ported`, `replay_infra` |
| `py.typed`, `tests/**` | — | n/a |

Public Rust path changes feed `tools/codegen/renames.toml` (one `[[rename]]` per moved public item): `gemini_genai::http::*` → `gemini_genai::api_client::*`; `error::*` → `errors::*`; `pager::*` → `pagers::*`; `auth_tokens::*` → `tokens::*`; `live::music::*` → `live_music::*`; `mcp::*` → `mcp_utils::*`; `afc::*` → `extra_utils::*` / `automatic_function_calling_util::*` per function; `converters::{getv,setv,…}` → `common::*`. Root re-exports in `lib.rs` of frequently used items (`Client`, `Error`) are kept so most users are unaffected; `Error` stays the crate error type name (`errors::Error`, re-exported at root).
